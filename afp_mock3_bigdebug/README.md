# AFP 第二轮全真演习 · 大规模版 — 真实体量的分诊战

## 体量(和你描述的真考对齐)
- pipeline.py:~165 行,13 个组件(其中 5 个是健康的,别碰绿代码)
- tests.py:**1363 行,236 个测试**;初始状态 **99 failures + 15 errors(共 114 个红灯)**
- 埋雷:8 颗,分布在 8 个组件里 —— 114 个红灯全部由这 8 颗雷引爆

## 规则
- **60 分钟硬钟**;零 AI;docs 可查;print/breakpoint 随便;只改 pipeline.py
- 不必全绿也算有效成绩(真考同款部分分);记录:全绿/停表时的红灯数 + 用时

## 本场要练的唯一技能:分诊,不是通读
1. 千万别从头读 tests.py —— 你 60 分钟读不完,真考也读不完
2. 先跑:`python3 tests.py 2>&1 | grep -E "^(FAIL|ERROR)"` 看失败清单
3. **按 TestClass 分组**:114 个红灯只来自 8 个组件 —— 红灯名就是病灶地图
4. 挑一个组件 → 只读它的 spec(docstring)+ 它的 2-3 个失败用例 → 修 → 重跑
   该类测试:`python3 -m unittest tests.TestSessionize -v`
5. 一个组件修好,一整片红灯同时变绿 —— 这就是真考里的得分节奏
6. 卡住一颗 >8 分钟就跳下一颗
