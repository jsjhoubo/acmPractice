# Workspace Layout

This workspace is split into two folders:

- `python/` for Python code and tests
- `cpp/` for C++ practice problems (LeetCode/ACM style)

## Python

- Entry: `python/src/main.py`
- Tests: `python/tests/`

## C++

- Problem files: `cpp/problems/`
- Use VS Code tasks:
  - `C++: Build Active File`
  - `C++: Run Active File`

Note: install a C++ compiler (`g++`, `clang++`, or MSVC) and ensure it is on PATH.
